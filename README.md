# vestiges
This is the first data uri I have ever developed for SHRINK, and it simply uses the input value from a slider to randomly draw squares of random colours and sizes and transparency onto a canvas.

## how to use it

Change the value of the slider by moving it and observe random sqaures spawning on the canvas.

## badges

- canvas
- interactive

## how to build it yourself
```
npm install
node build.mjs
```
